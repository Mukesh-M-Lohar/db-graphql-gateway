# db-graphql-gateway

Automatically generate a secure, production-ready GraphQL API from a database connection. 

## Features
- **Schema Discovery:** Automatically inspects your database schema and generates corresponding GraphQL types.
- **Relationships:** Resolves foreign keys to automatically wire up GraphQL associations.
- **Pagination:** Built-in Relay-style cursor pagination.
- **Authorization & Security:** Configurable JWT/OIDC support and query complexity/depth protection.
- **Performance:** Built-in DataLoader support to protect against N+1 query problems.
